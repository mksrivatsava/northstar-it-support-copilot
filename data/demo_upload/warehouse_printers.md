# Northstar Retail · Warehouse printers

## Zebra label calibration

For Zebra label calibration, pause the print queue and load the approved label stock. Hold the green feed button until two flashes, then release it to calibrate the media sensor. Print a test label before resuming the queue. If labels remain misaligned, record the printer asset tag and label dimensions and contact the warehouse support desk. This is a fictional demonstration procedure.
