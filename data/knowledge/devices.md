# Northstar Retail · Managed devices

## Slow laptop troubleshooting

For a slow laptop, save your work and restart the device. Close unused applications and check that at least 10 GB of disk space is free. Install approved updates through Software Center. If the laptop remains slow, send the device asset tag, operating system version, and approximate time the issue began to the service desk. Never disable antivirus or endpoint protection to improve performance.

## Software installation and approval

Install approved software from Software Center on your managed laptop. If an application is unavailable, create a software request with the business reason, vendor name, and manager approval. IT reviews security, licensing, and compatibility before deployment. Employees must not use personal administrator accounts or download unapproved installers.

## Lost or stolen laptop

Report a lost or stolen laptop immediately to the security team and service desk using another device. Include the asset tag if known, the last known location, and the approximate time of loss. Do not attempt to recover the device yourself. The security team manages remote lock and wipe decisions.
